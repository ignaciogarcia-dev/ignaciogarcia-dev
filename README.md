Software engineer from Uruguay. I build AI agents and LLM features, and the payment systems they run on, from the spec to production.

## Now

- **[Criptala](https://criptala.io)**: crypto exchange for Uruguay and Argentina. I lead its iOS and Android app and work on the core platform. I also built the system that settles bank deposits automatically, so the exchange runs 24/7.
- **[Kaufto](https://kaufto.com)**: a platform I built to create and run an online store, with a mobile app for shop owners. It includes an AI assistant, and an MCP server so owners can manage their store from their own AI agent.
